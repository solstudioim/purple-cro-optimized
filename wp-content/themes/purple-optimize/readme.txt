A conversion-focused WooCommerce child theme with restrained product, catalog, cart, and checkout layouts.

== Description ==

Purple Optimize is a block child theme for Woo's Purple theme. It provides a
warm editorial design system and focused layouts for the homepage, product
catalog, product detail, cart, and checkout journeys.

The theme contains presentation only. Optional conversion functionality is
maintained separately in the Purple Optimize Toolkit plugin and is not bundled
with this theme.

== Installation ==

1. Install the Purple parent theme from the upstream WooCommerce repository.
2. Install the Purple Optimize theme ZIP.
3. Activate Purple Optimize under Appearance > Themes.
4. Use WordPress 7.1+, PHP 7.4+, and WooCommerce 11.1+ for the commerce templates and blocks.

Parent theme source:
https://github.com/woocommerce/woocommerce/tree/trunk/themes/purple

== Frequently Asked Questions ==

= Does this theme include WooCommerce or the Purple Optimize Toolkit? =

No. Plugins are installed separately. The theme ZIP contains presentation files
only and requires the Purple parent theme.

= Where is the original Purple theme maintained? =

Automattic maintains Purple in Woo's public theme repository:
https://github.com/woocommerce/woocommerce/tree/trunk/themes/purple
